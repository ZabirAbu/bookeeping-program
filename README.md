# bookeeping-program
Accounting Program that initially lets the user choose the following options: Exit, Sales and Print. If the user types Exit, it terminates the program. 
If the user types Sales, the program will go to the Sales menu, where the user will need to enter the amount, item code, item price or go back to the main menu. 
If the user types Print will go to the Print menu where the user can choose whether to get the results to a file, to the screen or go back to the main menu.
